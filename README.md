# ISA_OnlyBuns_FE

Prikazivanje objave:
Korisnik ima mogućnost pregleda svojih objava i objava drugih korisnika putem dva taba. U prvom tabu prikazuju se objave korisnika, dok u drugom tabu korisnik može pregledati objave drugih. Svaka objava sadrži korisničko ime autora, datum kada je objava postavljena, opis objave, sliku (ako postoji), kao i broj lajkova koji je objava dobila.

Korisnik može interagovati sa objavama na sledeće načine:

- Lajkovanje objave.
- Pregled komentara na objavi.
- Dodavanje svog komentara na objavu.
- Brisanje svoje objave.
- Izmena sadržaja ili opisa svoje objave

Prikaz registrovanih korisnika:
Administrator ima pristup tabeli koja prikazuje sve registrovane korisnike. Tabela sadrži sledeće informacije o korisnicima: ime, prezime, email, broj postova.
Za lakšu pretragu i filtriranje, administrator može koristiti filtere koji se nalaze iznad tabele. Filtriranje se može izvršiti na osnovu:

- Imena korisnika
- Prezimena korisnika
- Email adrese korisnika
- Broja objava korisnika

Korisnik unosi podatke u odgovarajuće tekstualne okvire i aktivira filter pritiskom na odgovarajuće dugme. Takođe, ispod filtera nalazi se dugme za resetovanje, koje omogućava ponovni prikaz svih registrovanih korisnika, bez primenjenih filtera.
